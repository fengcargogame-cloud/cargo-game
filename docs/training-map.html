How the cargo agent trains

An AlphaZero-style loop with two additions for a deterministic single-player puzzle: the search tracks the best finished line next to the mean, and the best whole game found so far is fed back into every batch as an imitation target.

1 · The outer loop

Each episode plays one full game with search, stores one sample per move, then runs 8 gradient steps. The blue cycle is plain AlphaZero. The orange path is the elite line, which only runs with StaticGameConfig (same instance every episode).

2 · One move is three tree levels

An action is (piece, tunnel, placement). Instead of one huge branching factor, the tree splits it into three decisions, each with its own network head. Only the third level calls env.step.

3 · One simulation backs up two numbers

Because the game is deterministic and single-player, a finished line is a guaranteed result, not a sample. So each node keeps the usual running mean and the best real return seen through it, and selection uses a blend of both.

4 · The formulas

Selection score (PUCT)

score(a) = norm(Q(a)) + c · P(a) · √N(parent) / (1 + N(a))

c = 1.5. norm rescales Q to [0, 1] with the min and max seen in this search, so big penalties don't swamp the prior term.

mcts.py · _select, MinMaxStats

Child value used by selection

Q(a) = r + γ · [ (1−w)·mean + w·best ]

w = 0.5, γ = 1. An unvisited child borrows its parent's mean. With w = 0 this is plain AlphaZero.

mcts.py · Node.q, _child_q

Exploration noise

P ← (1−f)·P + f·Dir(α)

α = 0.5; f = 0.25 (dynamic) or 0.1 (static). Applied at the root's piece level, and on the tunnel and placement levels too unless noise_all_stages is off.

mcts.py · _add_dirichlet

Rollout policy

cost = 3·gap_cells + 8·overflow_cells

Piece drawn with odds ∝ exp(4·urgency − min cost), then its tunnel ∝ exp(−cost), then a random legal placement.

mcts.py · _waste, _rollout

Picking the move

π(a) = N(a) / Σb N(b)

Sampled from π for the first 8 moves (4 static), argmax after. The greedy evaluation game instead follows the best known finished plan and only switches if the search finds a better one.

mcts.py · visit_policy, pick · trainer.py · plan

Value target

zt = clip( Σk γk rt+k / 50, −1, 1 )

Return-to-go from move t, scaled by value_scale so it fits the tanh value heads. The same z trains all three value heads.

trainer.py · self_play_episode

Loss per batch

L = Σi∈{0,1,2} [ CE(πi, softmax(logitsi)) + (vi − z)² ]

Soft cross-entropy against the visit distribution at each stage, plus MSE for each value head. Heads 1 and 2 are run on the piece and tunnel that were actually played.

trainer.py · soft_ce, train_step

Elite samples

πi = one-hot(best line's move)

16 of every 64 samples come from the best game so far, so the policy is pulled toward that exact layout while the replay share keeps it general. Only active with elite_fraction > 0.
